# Constitution (Spec Kit)

Домашнее задание 5: эмуляция двух команд через второй SDD-фреймворк — GitHub Spec Kit.

## Принципы

1. **Spec before code.** Сначала согласуются две спецификации и общий контракт, только потом генерируется код.
2. **Library-first.** Логика живёт в отдельном модуле без HTTP и без UI, чтобы её можно было тестировать изолированно.
3. **Standard library only.** Никаких внешних зависимостей: `http.server`, `json`, `unittest`.
4. **Контракт — источник истины.** UI и логика не общаются напрямую; обе стороны следуют `contracts/api.md`.
5. **Проверяемость.** Каждое условие приёмки имеет автоматический тест или явную проверку.

## Границы

- Команда 1 отвечает за экран, действия, состояния и тексты ошибок.
- Команда 2 отвечает за данные, алгоритм, правила валидации и HTTP-ответы.
- Изменение контракта требует согласования обеих команд и записи в `contracts/api.md`.

## Definition of Done

- Обе спецификации согласованы и не противоречат контракту.
- `make test` проходит.
- Сквозной сценарий «UI → API → логика → ответ → UI-состояние» проверен тестом.
