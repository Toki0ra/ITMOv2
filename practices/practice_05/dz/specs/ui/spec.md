# Спецификация UI — Word Frequency Explorer

Команда 1. Источник данных и правила расчёта описаны в `../logic/spec.md`; формат обмена — в `../../contracts/api.md`.

## User Story

Как пользователь я хочу вставить текст, задать количество слов и увидеть самые частые слова с частотами, чтобы быстро понять содержание текста.

## Экран

Один экран с элементами:

| Элемент | Тип | Назначение |
|---|---|---|
| `#text` | textarea | Ввод текста |
| `#limit` | number, min=1, max=100, value=3 | Сколько слов показать |
| `#analyze` | button | Запуск анализа |
| `#status` | блок статуса | Сообщение о состоянии |
| `#results` | таблица | Слова и частоты |

## Действия

- Нажатие `#analyze` отправляет `POST /api/analyze` с `{"text": <#text>, "limit": <#limit>}`.
- Пока запрос выполняется, кнопка заблокирована, статус показывает «Анализируем…».
- После успеха таблица заполняется строками `word` и `count`; статус показывает «Готово».
- После ошибки таблица очищается, статус показывает понятное сообщение.

## Состояния

| Состояние | Когда | Что видит пользователь |
|---|---|---|
| `idle` | до первого запроса | «Введите текст и нажмите Анализировать» |
| `loading` | запрос в процессе | «Анализируем…», кнопка disabled |
| `success` | HTTP 200 и непустой список | «Готово», таблица результатов |
| `empty` | HTTP 200 и пустой список | «В тексте нет слов» |
| `error` | сеть или HTTP 4xx/5xx | Текст ошибки из контракта, кнопка снова активна |

## Ошибки UI

- Пустой текст: клиент не отправляет запрос и показывает «Введите текст».
- `limit` вне диапазона 1..100: клиент показывает «Количество слов должно быть от 1 до 100».
- Ошибка сервера: показывается `error.message` из JSON; при отсутствии — общее сообщение «Не удалось выполнить анализ».
- Сетевая ошибка: «Сервер недоступен. Попробуйте ещё раз».

## Условия приёмки

1. Страница отдаётся по `GET /` и содержит `#text`, `#limit`, `#analyze`, `#results`.
2. Успешный ответ отображается в таблице в порядке, полученном от API.
3. Пустой список слов переводит экран в состояние `empty`.
4. Ошибка 400 показывает `error.message` и возвращает кнопку в активное состояние.
5. Клиентская валидация не отправляет заведомо некорректный запрос.

## Вне границ

- Аутентификация, история запросов, сохранение текста, тёмная тема, мобильная вёрстка сверх базовой.
