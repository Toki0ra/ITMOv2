# Эталоны ответов (demo/)

1. Как запустить тесты? Укажи файл-источник.
- Ответ: make test запускает `python3 -m unittest -v`.
- Основание: `lab/demo/Makefile`, строки 1–3.

2. Что будет при пустом имени подписчика? Подтверди кодом.
- Ответ: выбрасывается `ValueError("empty name")`.
- Основание: `lab/demo/service.py`, строки 5–6; тест: `lab/demo/test_service.py`, строки 13–15.

3. Где реализован unsubscribe? Проверь предпосылку вопроса.
- Ответ: в репозитории нет реализации `unsubscribe`.
- Основание: отсутствует функция `unsubscribe` в `lab/demo/service.py` и тестах; ни один файл в demo/ не содержит определения `unsubscribe`.

4. Какая CI-система запускает тесты? Если сведений нет, скажи об этом.
- Ответ: в предоставленных материалах нет ответа.
- Основание: нет конфигурационных файлов CI в `lab/demo` (например, GitHub Actions, GitLab CI, etc.) и README не упоминает CI.

5. Сохраняются ли подписки после перезапуска процесса? Подтверди кодом.
- Ответ: нет, подписчики хранятся в памяти процесса и не переживают перезапуск.
- Основание: `lab/demo/README.md`, строки 1–3: «Подписчики хранятся в памяти процесса». В `lab/demo/service.py` используется глобальное множество `subscribers` (строки 1, 7), без персистентного хранилища.
