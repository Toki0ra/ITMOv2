# Proposal

## Why

В проекте есть минимальная библиотека метрик (`practices/practice_04/app/metrics.py`), но нет способа быстро посчитать, какие слова встречаются в тексте. Функция `wordcount` умеет только считать общее число слов, поэтому пользователю приходится писать разбор самостоятельно. Небольшая функция частот слов закрывает этот пробел и даёт основу для будущего поиска по контенту.

## What Changes

- Добавляется функция `word_frequencies(text: str) -> dict[str, int]` в модуль `app.metrics`.
- Токены выделяются по пробельным символам и приводятся к нижнему регистру; пунктуация не удаляется.
- Пустая строка и строка только из пробелов дают пустой словарь.
- Некорректный тип аргумента (не `str`) вызывает `TypeError`.
- Существующие `sum_list` и `wordcount` не меняются.

Не входит в изменение: удаление пунктуации, стемминг, поиск подстрок, топ-N, n-граммы, локализация и CLI-интерфейс.
