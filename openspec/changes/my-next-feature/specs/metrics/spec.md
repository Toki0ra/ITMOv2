# Spec Delta

## ADDED Requirements

### Requirement: Ранжирование слов по частоте
Система SHALL возвращать список пар «слово — частота», отсортированный по убыванию частоты, а при равной частоте — по возрастанию слова. Длина результата MUST быть не больше `limit`, значение по умолчанию — `3`.

#### Scenario: Самые частые слова
- **WHEN** вызывается `top_words("b a b c a b")`
- **THEN** возвращается `[("b", 3), ("a", 2), ("c", 1)]`

#### Scenario: Ограничение длины
- **WHEN** вызывается `top_words("a b c d", limit=2)`
- **THEN** возвращается `[("a", 1), ("b", 1)]`

#### Scenario: Равные частоты
- **WHEN** вызывается `top_words("c b a")`
- **THEN** возвращается `[("a", 1), ("b", 1), ("c", 1)]`

#### Scenario: Пустой текст
- **WHEN** вызывается `top_words("")`
- **THEN** возвращается пустой список

### Requirement: Проверка параметров ранжирования
Система SHALL отклонять некорректный текст возбуждением `TypeError`, а неположительный или нецелый `limit` — возбуждением `ValueError`.

#### Scenario: Неверный тип текста
- **WHEN** вызывается `top_words(None)`
- **THEN** возбуждается `TypeError`

#### Scenario: Неположительный limit
- **WHEN** вызывается `top_words("a", limit=0)`
- **THEN** возбуждается `ValueError`

#### Scenario: Нецелый limit
- **WHEN** вызывается `top_words("a", limit=1.5)`
- **THEN** возбуждается `ValueError`
