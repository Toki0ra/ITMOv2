# Proposal

## Why

После появления `word_frequencies` пользователю всё ещё нужно самостоятельно сортировать словарь, чтобы узнать самые частые слова. Готовая функция `top_words` делает этот сценарий одной операцией и задаёт стабильный порядок при равных частотах.

## What Changes

- Добавляется функция `top_words(text: str, limit: int = 3) -> list[tuple[str, int]]` в модуль `app.metrics`.
- Результат сортируется по убыванию частоты, при равенстве — по возрастанию слова.
- `limit` ограничивает длину результата и MUST быть положительным целым числом.
- Некорректный тип текста даёт `TypeError`; неположительный или нецелый `limit` даёт `ValueError`.
- Пустой текст даёт пустой список.
- Существующие `sum_list`, `wordcount` и `word_frequencies` не меняются.

Не входит: удаление пунктуации, стемминг, кэширование, CLI и потоковая обработка.
