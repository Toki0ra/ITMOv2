# metrics Specification

## Purpose

Предоставляет переиспользуемые числовые и текстовые метрики над входными данными, чтобы вызывающий код не реализовывал их повторно.

## Requirements

### Requirement: Подсчёт частот слов
Система SHALL возвращать отображение, в котором каждый токен текста, разделённый пробельными символами (пробел, табуляция, перевод строки), сопоставлен числу его вхождений. Ключи результата MUST быть приведены к нижнему регистру с помощью `str.lower()`.

#### Scenario: Повторяющиеся слова
- **WHEN** на вход подана строка `"the cat and the cat"`
- **THEN** результат содержит `the: 2`, `cat: 2`, `and: 1`

#### Scenario: Слова в разном регистре
- **WHEN** на вход подана строка `"Word word WORD"`
- **THEN** результат содержит `word: 3`

#### Scenario: Лишние пробелы и разные пробельные символы
- **WHEN** на вход подана строка `"  a\tb\n a "`
- **THEN** результат равен `{ "a": 2, "b": 1 }`

#### Scenario: Пунктуация сохраняется
- **WHEN** на вход подана строка `"cat, cat"`
- **THEN** результат равен `{ "cat,": 1, "cat": 1 }`

### Requirement: Пустой ввод
Система SHALL возвращать пустое отображение, если входная строка пуста или состоит только из пробельных символов.

#### Scenario: Пустая строка
- **WHEN** на вход подана строка `""`
- **THEN** возвращается пустой словарь

#### Scenario: Только пробелы
- **WHEN** на вход подана строка `"   \t\n"`
- **THEN** возвращается пустой словарь

### Requirement: Проверка типа аргумента
Система SHALL отклонять входные данные, не являющиеся строкой, возбуждая `TypeError`.

#### Scenario: Число вместо строки
- **WHEN** на вход подано число `123` или `0`
- **THEN** возбуждается `TypeError`

#### Scenario: Ложные значения не считаются пустой строкой
- **WHEN** на вход подано `None` или `False`
- **THEN** возбуждается `TypeError`

#### Scenario: Список вместо строки
- **WHEN** на вход подан список `["word"]` или пустой список `[]`
- **THEN** возбуждается `TypeError`

### Requirement: Сохранение существующего поведения
Система SHALL сохранять текущее поведение `sum_list` и `wordcount`, включая проверки типов и результаты, чтобы изменение не ломало существующих вызывающих.

#### Scenario: Сумма списка
- **WHEN** вызывается `sum_list([1, 2, 3.5])`
- **THEN** возвращается `6.5`

#### Scenario: Подсчёт слов
- **WHEN** вызывается `wordcount("  a   b c  ")`
- **THEN** возвращается `3`

#### Scenario: Некорректный тип в старых функциях
- **WHEN** вызывается `sum_list("oops")` или `wordcount(123)`
- **THEN** возбуждается `TypeError`
